# Student Performance Analysis Using NumPy & Statistics

## 📌 Project Overview

This project analyzes the academic performance of 5,000 students using Python, NumPy, Pandas, and statistical techniques.

The goal is to explore student performance, identify important patterns, and generate meaningful insights using descriptive statistics, NumPy operations, and data visualization.

---

## 🎯 Objectives

- Analyze academic performance of 5,000 students
- Calculate descriptive statistics
- Compare subject-wise performance
- Analyze grade distribution
- Identify top and bottom performing students
- Analyze study hours and academic performance
- Analyze attendance and academic performance
- Calculate correlations between variables
- Classify students based on performance
- Create meaningful data visualizations

---

## 📊 Dataset

The dataset contains **5,000 student records** and includes the following attributes:

| Column | Description |
|---|---|
| Student_ID | Unique student identifier |
| Age | Age of the student |
| Gender | Gender of the student |
| Study_Hours | Average daily study hours |
| Attendance | Attendance percentage |
| Math_Score | Mathematics score |
| Science_Score | Science score |
| English_Score | English score |
| Computer_Score | Computer Science score |
| Total_Score | Total marks across subjects |
| Percentage | Overall percentage |
| Grade | Academic grade |
